# MZ-1500 Sound IDE UI 仕様書 (`docs/specification/ui.md`)

本書は、MZ-1500用サウンドドライバ・MMLコンパイラ向け統合開発環境（IDE）のWebフロントエンドに関するUI仕様・デザインルール・各コンポーネントの挙動をまとめたドキュメントです。機能追加や変更に伴い随時追記・更新します。

---

## 1. デザインコンセプト & テーマ仕様 (Linear Style + Bento Grid DAW Theme)

### 1.1 テーマ概要
プロフェッショナルな最新DAWやモダン開発ツール（Linear等）の洗練されたダークテーマを取り入れ、**長時間作業でも目が疲れないマットダークサーフェス**と**視覚的ヒエラルキーが明確なBento Gridレイアウト**を採用。
背景の方眼グリッドや全面ネオン装飾を廃止し、境界線や静的テキストは落ち着いたニュートラルグレー（`#71717a` / `border-white/[0.08]` 等）を基調とします。操作可能なスライダーのつまみやアクティブなボタン・VUメーターにのみピンポイントでアクセントカラーを発光させ、「どこがクリック・操作可能か」が一目で判別できるプロクオリティのGUIを提供します。

### 1.2 カラーパレット & サーフェス階層 (Linear Surface System)
| 階層 / 用途 | カラーコード / Tailwindクラス | 適用場所 |

| **Base Surface** | `#090a0f` | アプリルート背景、キャンバス最深部 |
| **Panel Surface** | `#0e1017` / `#11131a` | メインヘッダー、エクスプローラー、右ペイン背景 |

### 1.3 共通コンポーネント規格 & Bento Grid 規約
- **Bento Card**: 各機能モジュールは角丸 `rounded-lg` (8px) の独立カードに格納し、1pxの控えめなボーダー（`border-white/[0.08]` または `#3C3C3C`）で整理。
- **入力要素の高さ**: ボタン・セレクト・入力欄は `h-6` (24px) 〜 `h-7` (28px) で統一。
- **自照式・アクティブ表現**: ボタンがアクティブ時のみ背景とボーダーがアクセントカラー（クリアブルー `#00A8FF` 等）で発光し、非アクティブ時はダーク背景に溶け込む。
- **スライダー**: トラック背景は極細のダークグレー、つまみ（Thumb）のみが鮮やかなクリアブルー（`#00A8FF`）に発色し、マウスホバー時にグローを強調。
- **グラフキャンバス**: 不要な背景グリッドやグラデーション塗りを廃止し、極薄の目盛り線と鮮明な折れ線・操作ノードで構成。

## 2. 画面レイアウト構成

FlexboxおよびCSS Gridを活用し、解像度変化に追従するペイン分割レイアウト。

```
+---------------------------------------------------------------------------------+
| HEADER: アプリ名 (MZ-1500 IDE) | アクション群 (BUILD, PLAY, STOP, MZT) | [HIDE PANE] |
+---------------------------------------+-+---------------------------------------+
| LEFT PANE (中央ペイン / 可変幅 20%〜100%): |S| RIGHT PANE (開閉式 / タブ切り替え):    |
| +-----------------------------------+ |P| [📊 TRACK] [∿ TONE] [📈 VOL] [↗ PITCH] |
| | [EXPLORER] | MMLエディタ           | |L| [⚙ SETTINGS]                          |
| +-----------------------------------+ |I| - トラックモニタ & 各エディタ & 設定    |
| | BOTTOM: システムコンソール          | |T|                                       |
| | (ビルド・エラーログ / READY.)      | | |                                       |
| +-----------------------------------+ | |                                       |
+---------------------------------------+-+---------------------------------------+
```

### 2.1 左右ペインスプリッター (リサイザー) & 開閉トグル
- **ドラッグ操作による比率変更**: 左右境界バー（当たり判定 10px / 見た目 4px）をマウスドラッグすることで、20%〜80% の範囲で自在に幅をリサイズ可能。
- **堅牢なイベント制御**: `onMouseDown` 時にネイティブイベントリスナーを即座に登録し、ドラッグ中の全画面オーバーレイにより Monaco Editor のマウス奪取・テキスト選択を完全に防止。
- **視覚的フィードバック**: 通常時はボーダー色、ホバーおよびドラッグ中はQDブルー（シアン発光）に変化。中央にハードウェア風の点線グリップを表示。
- **ダブルクリックリセット**: スプリッターバーをダブルクリックすると即座に 50%:50% の初期比率に復帰。
- **右ペイン開閉トグル (`[HIDE] / [PANE]`)**: **MMLエディタタブバーの最右端**に配置（左端のエクスプローラー開閉ボタンと左右対称の配置）。ワンクリックで右ペインを非表示にしてエディタエリアを全幅（100%）に最大化可能。もう一度押すと直前の分割比率で即座に復帰。

### 2.2 エクスプローラースプリッター (左ペイン内リサイザー)
- **幅リサイズ (140px〜460px)**: エクスプローラーとMMLエディタ間の縦境界バーをドラッグして幅を自在に伸縮可能。ダブルクリックで標準幅（240px）にリセット。

### 2.3 エディタ下部スプリッター & タブ化パネル (上下リサイザー & PROBLEMS / CONSOLE タブ)
- **エクスプローラーの右側領域**において、[Monaco Editor] ⇔ [下部タブパネル (PROBLEMS / CONSOLE / 将来拡張エリア)] の境界に水平スプリッターを配置。
- **タブ切り替えによるエリア集約**:
  - 従来上下2段だったコンパイルエラー（PROBLEMS）とシステムコンソール（CONSOLE）をタブコンテナとして統合。
  - 将来的に別エリア（逆アセンブラ、メモリマップ、波形プレビューなど）を同エリアへシームレスに追加可能な拡張スロット構造を採用。
- **マウスドラッグによる高さ変更**:
  - エディタ ⇔ 下部タブパネル境界をドラッグし、高さを 60px〜480px で自在に伸縮可能（ダブルクリックで初期高さ 160px にリセット）。
  - ドラッグ中は全画面オーバーレイで `cursor-row-resize` を捕捉し、Monaco Editor のイベント奪取を防ぎスムーズに上下リサイズ。

## 3. コンポーネント詳細仕様

### 3.1 ヘッダー領域 (`Header`)
- **背景デザイン**: MZ-1500実機およびQD（クイックディスク）ドライブの象徴である**QDテクニカル方眼グリッド背景（主線48px / 副線12pxのシアン複線グリッド）**を適用。
- **ロゴ**: 
  - 左端にQDシアン自照式バッジ `MZ` を配置（`bg-cyan-950` / `border-cyan-400` / ネオングロー、力強い極太ボールド `font-black text-sm`）。
  - タイトル表記: `MZ-1500 IDE`（`IDE` をMZレッドで強調表示）
- **トランスポートアクションボタン**:
  - `🔁 LOOP`: MMLの `L` コマンドによる無限ループの有効/無効トグルボタン（自照式LEDランプ付き、デフォルト: **ON**）。OFF時は曲末尾または1周で再生停止。
  - `▶ PLAY / STOP / PLAYING`: MMLのビルド（コンパイル）および再生開始をワンクリックで実行。
    - **トグル動作**: 再生中に押すと即座に停止（`handleStop`）。
    - **ショートカットキー**: `Ctrl + Enter`（Mac: `Cmd + Enter`）でグローバルおよびMonaco Editor内から即座に再生/停止トグルが可能。
    - 再生中は自照式シアン発光パルスアニメーションを表示。
  - `■ STOP`: 再生停止ボタン（保持）。
  - `EXPORT (.qdf)`: 実機QuickDisk（QD）用イメージ形式（`.qdf`）バイナリエクスポート。

---

### 3.2 MMLエディタ & 下部タブパネル (`MmlEditor.tsx`, `FileExplorer.tsx`, `CompileErrorPanel.tsx`)
- **左ペイン配置**
- **ファイルエクスプローラー (`FileExplorer.tsx`)**:
  - 左端に折りたたみ可能なツリービューサイドバー（幅 240px）を配置。
  - **エクスプローラー開閉トグル**: タブバー最左端のアイコンボタン（`PanelLeftClose` / `PanelLeftOpen`）で表示/非表示を切替可能。
  - **Sample MML（プリセット）**: デモ楽曲（`demos/`）やテンプレート（`templates/`）をツリー表示し、クリックでエディタのタブに即時展開。
  - **Local Files（ローカルフォルダ）**:
    - `OPEN FOLDER...` ボタンによりローカルフォルダの選択・表示が可能（モック）。
    - ツールバーより「新規MMLファイル作成 (`📄+`)」「新規フォルダ作成 (`📁+`)」を実行可能。
    - 各ファイル/フォルダのホバーアクションで「インラインリネーム (`✏️`)」「削除 (`🗑️`)」が可能。
- **複数ファイル・タブ管理 (`MmlEditor.tsx`)**:
  - 上部にタブバーを配置。エクスプローラーからのファイル選択や、新規タブ作成（`+`）、タブ閉じる（`×`）に対応。
  - タブバー最右端に**右ペイン開閉トグルボタン（`HIDE` / `PANE`）**を配置。
  - アクティブなタブはQDブルーの上部ボーダーおよび発光シャドウで強調。
- **エディタコア**: Monaco Editor (`vs-dark` テーマ)
- **タイポグラフィ**: カスケードコード/等幅フォント、フォントサイズ 12.5px、行高 20px（情報密度向上）、行ハイライト、ミニマップ非表示、Ctrl+マウスホイールによるズーム対応、Monaco上での `Ctrl+Enter` 再生/停止キーバインド登録。
- **右クリックコンテキストメニュー & 各エディタ連携 (`MmlEditor.tsx` / `src/utils/mmlContextParser.ts`)**:
  - Monaco Editor のネイティブコンテキストメニューへ、`MML_NAVIGATION` / `MML_NEW` の2グループ・計6アクションを登録:
    - `@N を TONE エディタで編集`: 右クリックした行を解析し `@N` / `@FMN` があれば、右ペインをYM2151 TONEに自動切替（非表示時は自動オープン）して該当IDをロード。
    - `@VEN を VOL ENV エディタで編集`: 行内の `@vN` / `@VEN` を解析し、VOL ENVタブへ切替して該当IDをロード。
    - `@PEN を PITCH ENV エディタで編集`: 行内の `@PEN` を解析し、PITCH ENVタブへ切替して該当IDをロード。
    - `新規 FM TONE を挿入...` / `新規 VOL ENV を挿入...` / `新規 PITCH ENV を挿入...`: MML全文から既存IDを収集し、**最大ID+1の未使用ID**で各エディタを新規作成状態で開く。
    - **メニューアイコンは右ペインタブと同一の Lucide SVG**（`AudioWaveform` / `TrendingUp` / `ChartLine`）。Monaco 内蔵メニューは Lucide アイコンを表示できないため、**カスタムコンテキストメニューコンポーネント（[`src/components/MmlContextMenu.tsx`](./src/components/MmlContextMenu.tsx)）による overlay 方式**を採用（Monaco `contextmenu: false` 化 + エディタラッパーの `onContextMenu` で `preventDefault`）。
    - メニューは「編集」系を対象IDを含む行でのみ表示し、区切り線を挟んで「新規〜を挿入...」3種を常時表示。外クリック / `Esc` / ウィンドウ非活性で閉じ、画面端では表示位置を自動補正。
  - 行解析ユーティリティは `src/utils/mmlContextParser.ts` に純粋関数として分離:
    - `analyzeMmlLine`: 1行から `@N` / `@FMN`、`@vN` / `@VEN`、`@PEN` のIDを抽出。コメント (`;` / `//`) 以降は解析対象外。他コマンド (`@WN`, `@SW`, `@q` 等) を音色IDへ誤検出しない。
    - `collectUsedIds`: MML全文から3種類のID使用済みセットを収集。
    - `nextAvailableId`: 未使用IDの採番（最大ID+1、空なら1）。
    - ロジック検証スクリプト: `scripts/verify-mml-parser.mjs`（`node scripts/verify-mml-parser.mjs` で実行、全ケース自動アサート）。
  - 「編集...」系アクションは、対象IDがその行に存在しない場合は何もしない（安全ガード）。
- **各エディタ ⇔ MML の双方向連携（「▶ MMLに反映」ボタン）**:
  - FM TONE / VOL ENV / PITCH ENV の各エディタヘッダーにエメラルド系の `▶ MMLに反映` ボタンを配置。クリックすると現在の編集内容をMMLコマンド定義に変換し、**Monaco Editor のカーソル位置に挿入**（選択範囲がある場合は置換）する。
    - FM TONE: `@N /* 音色名 */ { ALG, FB, OP1〜OP4 パラメータ }` の複数行ブロック。
    - VOL ENV: `@vN = { |L / |R マーカー付き音量列 }` の1行定義。
    - PITCH ENV: `@PEN = { |L / |R マーカー付きピッチ列 }` の1行定義。
  - エディタ側は `loadToneId` / `loadEnvId` props を監視し、右クリックメニューで指定されたIDをIDセレクタへ即時反映。
  - 挿入されたMMLスニペットは通常のエディタコンテンツとして扱われ、プレビュー再生用パラメータ（マスターボリューム等）には影響しない。
- **下部タブパネル (`BottomPanel` / `VirtualKeyboard.tsx`, `CompileErrorPanel.tsx`)**:
  - エクスプローラーの右側、Monaco Editor の下に配置。高さは上下スプリッターで自由に伸縮可能（60px〜480px、標準180px）。
  - **タブ一覧**:
    - `[🎹 KEYBOARD]`: バーチャルキーボード。コンパクトな2段構成（上部設定コントロールバー、下部横スクロールフル88鍵）。
      - **フル88鍵盤（A0〜C8）**: 白鍵52・黒鍵36を高精細DAWスタイルで描画。押下時にシアンネオングロー。C鍵盤（C1〜C7）にはオクターブラベル表示。
      - **オクターブクイックジャンプ**: 上部の `C1`〜`C7` ボタンで目的のオクターブへスムーズスクロール。
      - **コンテキスト連動機能**:
        - **MMLエディタ**: Monaco Editor のキャレット位置からトラック（PSG / FM / BEEP / NOISE）、音色（`@`）、オクターブ（`o`）、音量（`v`）、エンベロープ（`@v`, `@PE`）、デチューン（`D`）を自動解析して演奏。
        - **FM TONEエディタ**: 編集中の4オペレータFM音色データ（ALG, FB, 各OPパラメータ）を即座に適用して演奏。ピッチ/デチューンプルの手動指定も可能。
        - **PITCH ENVエディタ**: 編集中のピッチ変調カーブを適用してリアルタイム発音（FM / PSG / BEEP 選択可）。
        - **VOL ENVエディタ**: 編集中のボリュームエンベロープカーブを適用してリアルタイム発音（PSG / NOISE、PITCH ENV併用可）。
      - **コントロールバー機能**: CHIP選択（AUTO / PSG / FM / BEEP / NOISE）、FM VOICE選択、PITCH ENV / VOL ENV適用トグル、PITCH/DETUNEプルダウン指定、音量スライダー（v0〜v15）、PANIC（全音停止）ボタン。
    - `[PROBLEMS (X)]`: コンパイルエラー・警告一覧。エラー数・警告数に応じたカラーバッジ（赤/黄/グレー）表示。クリックでソースコード該当行へのジャンプシミュレーション。右側に `CLEAR` ボタン。
    - `[CONSOLE (Y)]`: システムコンソールログ。ビルド、エクスポート、再生、ループモードログをリアルタイム出力。右側に `CLEAR` ボタン。
    - 将来的な拡張タブ枠を確保。

### 3.3 トラックモニター (`TrackMonitor.tsx`)
右ペインの第1タブに配置。音源チップの稼働状況を可視化するリアルタイムモニタパネル。

#### 1) 対応音源および全17チャンネル構成
2カラムレイアウトで視認性を確保。実機標準音源（DCSG & BEEP）を左側に、拡張FM音源（ACZ-8BS1MZ）を右側に配置。
- **左カラム: MZ-1500 BASICS (計9ch) [実機標準]**
  - タイトル: `MZ-1500 BASICS`、バッジ: `STANDARD 9ch`
  - パネルヘッダーに `ALL ON` / `MUTE` ボタンを備え、標準音源9ch全体を一括プレビュー制御可能。
  - パネル内部をチップ系統ごとの3つのサブカテゴリに整流化：
    - **DCSG 1 (SN76489)**: `P1`～`P3` (`PSG1`～`PSG3`) ＋ `N1` (`Noise1`)
    - **DCSG 2 (SN76489)**: `P4`～`P6` (`PSG4`～`PSG6`) ＋ `N2` (`Noise2`)
    - **BEEP**: `B1` (`BEEP`, 1-bit Pulse 8253 Timer)
  - テーマカラー: 全体統一されたQDブルー＆スレートグレー基調。ミュート等の重要アラートのみMZレッドを使用。全体の色数を抑え洗練された質感に統一。
- **右カラム: YM2151 (ACZ-8BS1MZ 4オペレータFM音源 8ch) [拡張ボード]**
  - トラック表記: `F1`～`F8`
  - サブラベル: `FM1`～`FM8`
  - テーマカラー: QDブルー（シアン）

#### 2) 各トラック行の表示項目

### 3.4 YM2151 (OPM) FM 音色エディタ (`FmToneEditor.tsx`)
右ペインの第2タブ（`YM2151 TONE`）に配置。MZ-1500用拡張FM音源ボード「ACZ-8BS1MZ」（YM2151 / OPM）の4オペレータFM音色を視覚的かつ直感的に編集する高機能エディタ。
- **4.1 ヘッダー部（グローバル設定 & プリセット）**:
  - **プリセット選択**: `E.PIANO 1`, `SLAP BASS`, `BRASS ENSEMBLE`, `CRYSTAL BELL` など実用的な音色をワンタッチロード。
  - **アルゴリズム (ALG 0〜7)**:
    - 8つのトグルボタンを横並びに配置。
    - **実機準拠の高精細オペレータ接続ブロック図（SVGアイコン）**:
      - ヤマハ公式・OPM仕様に厳密に準拠した4オペレータ（`1`〜`4`）の直列・並列接続、変調配線、合流・分岐ライン、および音声出力矢印（`↓`）を精密に描画。
      - 各オペレータは番号（`1`〜`4`）入り正方形ボックスで表現。
        - **OP1 フィードバックループ配線**: 全てのアルゴリズムにおいて、OP1から出てOP1に再び入力する自己ループ線（矢印付き）を描画し、OP1にフィードバックがかかっていることを視覚的に明示。
        - **白塗りキャリア表現（ミニマル＆ハイコントラスト）**: 余計な有彩色を排し、音声出力となるキャリアOPを「白塗りボックス + 濃紺文字」で表現。アクティブ時は純白発光、非アクティブ時はライトスレート白塗りとし、モジュレータ（中抜きボックス）と直感的に区別。
        - **アクティブ時ハイライト**: 選択中のアルゴリズムはQDシアンネオン枠で強調。
        - 選択中ALGに応じてオペレータ編集部の「キャリア (`CARRIER [OUT]`)」と「モジュレータ (`MODULATOR`)」の役割表示および物理配線オーバーレイ・シグナルフローバーが即座に連動切り替え。
    - **各アルゴリズムの接続定義**:
      - `ALG 0`: `1` ➜ `2` ➜ `3` ➜ `4` ➜ `↓` （Carrier: `4`）
      - `ALG 1`: (`1` + `2`) ➜ `3` ➜ `4` ➜ `↓` （Carrier: `4`）
      - `ALG 2`: (`1` + (`2` ➜ `3`)) ➜ `4` ➜ `↓` （Carrier: `4`）
      - `ALG 3`: ((`1` ➜ `2`) + `3`) ➜ `4` ➜ `↓` （Carrier: `4`）
      - `ALG 4`: (`1` ➜ `2` ➜ `↓`) + (`3` ➜ `4` ➜ `↓`) （Carrier: `2`, `4`）
      - `ALG 5`: `1` ➜ (`2` + `3` + `4`) ➜ `↓` `↓` `↓` （Carrier: `2`, `3`, `4`）
      - `ALG 6`: (`1` ➜ `2` ➜ `↓`) + `3` ➜ `↓` + `4` ➜ `↓` （Carrier: `2`, `3`, `4`）
      - `ALG 7`: `1` ➜ `↓` + `2` ➜ `↓` + `3` ➜ `↓` + `4` ➜ `↓` （全並列、Carrier: `1`, `2`, `3`, `4`）
  - **フィードバック (FB 0〜7)**:
    - スライダーおよび微調整ボタンにより直感的に数値を設定可能。
  - **MML出力 & クリップボードコピー**:
    - `@N /* 音色名 */ { ALG, FB, OP1〜OP4 (AR, D1R, D1L, D2R, RR, TL, MUL, DT1, DT2) }` 形式のMML音色定義ブロック（`mml_reference.md` 準拠の複数行コマンド形式）をリアルタイム生成し、ワンクリックでコピー可能。
    - ヘッダー部の `▶ MMLに反映` ボタン（エメラルド系）により、同一生成ロジック（`generateMmlSnippet`）の出力をMMLエディタのカーソル位置へ直接挿入可能。
  - **Web Audio 4-Op FM 合成プレビュー**:
    - `▶ TEST NOTE (C4)` / `■ STOP` ボタンにより、Web Audio APIのOscillatorNodeとGainNodeを用いて選択中ALG・各OPパラメータに忠実な4オペレータFM変調サウンドをリアルタイム試聴可能。

- **4.2 オペレータ編集部（OP1〜OP4）**:
  - 4つのオペレータを**2×2のグリッド配置**で表示（上段: `OP1`, `OP2` / 下段: `OP3`, `OP4`）。
  - **OP同士の接続構造のビジュアル表現**:
    - **接続ルート表示（`SIGNAL ROUTE`）**: 2×2グリッド直上に配置。ボタンと誤認されないよう立体的な枠線やバッジを排し、落ち着いたテキストベースのインライン表記（例: `SIGNAL ROUTE: ( ( OP1 ⟲6 ➜ OP2 ) + OP3 ) ➜ OP4 (out) ➜ OUT`）で静的なインフォメーションとしてシグナル経路を明示。
    - **各オペレータのI/Oストリップ**: 各パネル上部に `IN:`（変調元または `PURE SINE` / `FB[x]`）と `OUT:`（変調先または `🔊 DAC AUDIO`）を常時表示し、オペレータ単体を見ても入出力関係が即座に判別可能。
    - ※パネル間の重なり配線矢印オーバーレイは、画面の煩雑さを解消するため廃止し、すっきりとしたパネル構成に統一。
  - 各パネルが横幅を広く確保でき、エンベロープ波形および各スピンボックス・スライダーを余裕を持って快適に編集可能。
  - **ヘッダー & コントロール**:
    - オペレータラベル表示（`OP1 (M1)`, `OP2 (C1)`, `OP3 (M2)`, `OP4 (C2)`）。
    - **キャリア/モジュレータ動的バッジ**: 選択中ALGに基づいて、出力段となるキャリアには自照式シアンの `CARRIER [OUT]`、変調段にはスレートの `MODULATOR` バッジを明示。
    - **[M] Mute / [S] Solo ボタン**: VS Codeスタイルのコンパクトなフラットボタントグル。各オペレータのプレビュー出力を個別ミュート/ソロ可能。
    - **[Copy] / [Paste] ボタン**: オペレータ単位のパラメータ（全11項目）をクリップボード感覚で別のオペレータへ一発複製可能。
  - **出力 & ピッチパラメータ (ゆったりした入力サイズ)**:
    - **TL (Total Level)**: 0〜127（0=最大、127=消音）の操作しやすいスライダー（高さ1.5）＆数値入力。
    - **MUL (Frequency Multiple)**: 0〜15（0.5倍〜15倍波）。高さ28px（`h-7`）・太字のゆったりしたセレクトボックス。
    - **DT1 (Detune 1)**: 0〜7（ピッチ微調整）。高さ28px（`h-7`）・太字セレクトボックス。
    - **DT2 (Detune 2)**: 0〜3（粗いピッチオフセット）。高さ28px（`h-7`）・太字セレクトボックス。
  - **エンベロープ編集部（カスタムスピンボタン & インタラクティブCanvas曲線）**:
    - **押しやすいカスタム上下ボタン付きスピン入力 (`SpinInput`)**:
      - `AR` (0〜31), `D1R` (0〜31), `D1L` (0〜15), `D2R` (0〜31), `RR` (0〜31)。
      - 高さ28px（`h-7`）の余裕ある入力ボックスに、独立したカスタム上下ボタン（`▲` / `▼`、幅20px）を配置。ブラウザ標準の小さなスピン矢印を廃止し、マウスで確実にクリック可能。
      - ページ全体のスクロール操作を妨げないよう、数値ボックス上での誤操作・意図しない値変化を防止（上下スピンボタン、キーボード直接入力、Canvasグラフノード操作により確実に変更可能）。
      - 直接のキーボードタイピング入力も可能。
    - **QD方眼グリッド付きエンベロープ曲線Canvas**:
      - **クッキリとした単色QDブルー折れ線**: グラデーション塗りを廃止し、スライダー等と統一されたシャープなQDブルー（`#06b6d4`）のラインのみを描画。
      - **拡大ドラッグノード（〇）**: 直径11px〜13px（`r = 5.5〜6.5`）にサイズを拡大し、QDブルー塗りつぶし＋純白の輪郭線によりダーク背景でも視認性抜群。
      - **ピクセルベース高精度当たり判定 & Pointer Eventsによる滑らかなドラッグ追従**:
        - アスペクト比に依存しないピクセル距離計算（半径18px）により、ノードを確実にクリック可能。
        - Pointer Events（`setPointerCapture`）とドラッグ開始位置からの累積変位方式を採用。クロージャによる値固定や微小移動時のブルブル振動を根本解消し、マウス移動量に1対1で滑らかに数値・グラフ波形が追従。キャンバス外にマウスが外れても追跡を継続。
      - **操作方向に応じた動的マウスカーソル表現**:
        - `AR`（アタックレート）: 左右時間のみ変更可能 ➜ `ew-resize`（`↔`）
        - `D1`（ディケイ1変曲点）: 左右時間＋上下サステインレベル変更可能 ➜ `move`（全方位）
        - `D2`（ディケイ2終了点）: 上下減衰深度のみ変更可能 ➜ `ns-resize`（`↕`）
        - `RR`（リリースレート）: 左右時間のみ変更可能 ➜ `ew-resize`（`↔`）
      - ノードホバー/ドラッグ時のシアン発光＆拡大エフェクト、キャンバス下部のリアルタイムパラメータ解説ガイド付き。
  - **オペレータ選択 & 選択解除インタラクション**:
    - 通常クリック（Shift/Ctrlなし）時、未選択のOPをクリックするとそのOPのみを選択し他を解除。
    - すでに選択されているOPの `[SELECTED]` ボタンまたは余白をクリックした場合は**即座に選択解除（トグルオフ）**。
    - Shift / Ctrlキー押下時は、従来通り個別トグルによる複数選択に対応。
  - **複数選択時の直接数値入力（絶対値反映）と相対同期編集（ハイブリッド連動）**:
    - **直接数値入力 (Absolute Mode)**: 数値入力テキストボックスへキーボードで直接数値をタイピング入力した場合（またはセレクトボックスで選択した場合）、**入力した値そのものが選択中の全OPへ一括適用**され、指定の値へ瞬時に揃えることが可能。
    - **上下ボタン・ホイール・グラフドラッグ (Relative Mode)**: スピンボタン（`▲` / `▼`）、マウスホイール、Canvasエンベロープグラフのドラッグ、TLスライダーを操作した際は、他の選択中OPへ**操作元OPの変化差分（delta = newVal - oldVal）を相対的に加算・反映**。
    - 各パラメータの許容範囲（`TL: 0〜127`, `AR/D1R/D2R/RR: 0〜31`, `D1L/MUL: 0〜15`, `DT1: 0〜7`, `DT2: 0〜3`）で安全にクランプ。
    - 各OP固有のエンベロープ比率を活かした微調整と、同一値への一括リセット・統一入力の双方がシームレスに両立。

### 3.6 ピッチエンベロープエディタ (`PitchEnvelopeEditor.tsx`)
右ペインの第4タブ（`PITCH ENV`）に配置。主にDCSGやPSG、FM音源の1フレーム単位（1/60秒）のピッチオフセット（周波数変調・デチューン・ビブラート・ポルタメント）を直感的にグラフィカル編集するエディタ。Bento Grid DAWスタイルを適用。

- **Bento Card 構成**:
  - **Bento Card 1 (ヘッダー & トランスポート & プリセット)**:
    - タイトル、音源種別バッジ（`VIBRATO & BEND`）、IDセレクタ（`@PE0`〜`@PE15`）。
    - リアルタイム試聴トランスポート（`▶ TEST TONE` / `■ STOP`）。
    - トランスポート右横に `▶ MMLに反映` ボタン（エメラルド系）。クリックで `@PEN = { ... }` 定義をMMLエディタのカーソル位置へ挿入。
    - ビブラート特化プリセット（ワンクリックロード）:
      - `VIBRATO (MILD)`: 自然で心地よい浅いビブラート（レンジ±7, 周期12F）。
      - `VIBRATO (DEEP)`: 深く揺れるダイナミックなビブラート（レンジ±15, 周期12F）。
      - `DELAYED VIB`: ストレート発音後にビブラート開始（12F以降ループ）。
      - `PITCH DROP`: 高音から急激に落ちるレーザー・効果音（レンジ±24）。
      - `PITCH UP`: 低音から素早く立ち上がるベンドアップ（レンジ±24）。
      - `FAST TRILL`: 高速で2音間を行き来するトリル（レンジ±7）。
    - ループ（`|L`）/ リリース（`|R`）の現在ステップ状態バッジ（ワンクリック解除ボタン付き）。
  - **Bento Card 2 (タイムライン & ダイナミックレンジ & 編集ツールバー)**:
    - **フレーム長可変（2〜128F）**: クイック長指定（`16F`, `32F*`, `64F`, `128F`）および `+` / `-` 微調整。
    - **用途に応じたダイナミックレンジ切替 (PITCH RANGE)**:
      - `±7` (Micro/Vib: 微小デチューン・浅いビブラート)
      - `±15` (Standard: 標準ビブラート・効果音)
      - `±24` (2 Octaves: 2オクターブ・ポルタメント)
      - `±48` (Wide Bend: ワイドピッチベンド・急降下/急上昇)
      - レンジ切替時も既存データを自動クランプしてシームレスに編集可能。
    - **プロDAW波形クイック編集ツール (TOOLS)**:
      - `GEN VIB ~`: 設定中レンジの約半分の振幅で周期8Fの正弦波ビブラートをタイムライン全体へ自動生成。
      - `INVERT ⇅`: ピッチ正負反転（`pitch * -1`）。
      - `FLIP ⇄`: タイムライン左右反転。
      - `SMOOTH`: 前後フレームの重み付き移動平均によるスムージング。
      - `CENTER 0`: 全ステップを 0（ピッチシフトなし）に一括リセット。
      - **波形・ピッチシフト (SHIFT)**:
        - `[→] 右シフト`: タイムラインを1ステップ右へシフト（先頭にStep 0の値を複製挿入）。
        - `[←] 左シフト`: タイムラインを1ステップ左へシフト（末尾に最終Stepの値を複製挿入）。
        - `[↑] 上シフト`: 全ステップのピッチを +1 加算（上限 +RANGE でクランプ）。
        - `[↓] 下シフト`: 全ステップのピッチを -1 減算（下限 -RANGE でクランプ）。
    - **タイムライン縦横同時ズーム & 水平スクロールパン**:
      - ズーム（`-`, `100%`, `+`, `Ctrl + マウスホイール` による60%〜350%拡縮）。
      - `Space` キー押下ドラッグによる左右スクロール（パン）。
    - **リアルタイムカーソル位置表示**: `POS: F[step] : P[pitch]`（正負符号付き）。
  - **Bento Card 3 (メイン・ピッチスタジオキャンバス)**:
    - **センターゼロ基準の双極性バーグラフ (Bipolar Bar Graph)**:
      - 中央の 0 レベルに白の破線基準ライン（センターライン）を配置。
      - プラス方向（ピッチ上昇）はQDシアン（`cyan-400`）の上向きバー。
      - マイナス方向（ピッチ下降）は温かみのあるアンバー（`amber-400`）の下向きバー。
      - 0レベル時はセンタードットで表示。
      - 再生中のステップにはシアンの縦ラインオーバーレイをリアルタイム追従描画。
    - **DAW風リージョン可視化**: ループ区間（`bg-cyan-500/[0.03]`）とリリース区間（`bg-amber-500/[0.03]`）の透過帯と上部ブラケット。
    - **直接指定マーカーレーン**: `|L LOOP` と `|R RELEASE` の自照式ボタントグル行。
    - **均等スロット & 線形補間（Interpolation）ドラッグ描画**:
      - 素早いペンドラッグでも虫食い抜けのない一筆書き描画。
      - **バー上マウスホイール連動**: バーグラフ領域でマウスホイールを上下スクロールすると、カーソル位置のステップのピッチが 1 ずつダイレクトに増減（-RANGE〜+RANGEクランプ）。Ctrl+ホイールのタイムラインズームとも安全に共存。
  - **Bento Card 4 (MML コマンド出力 & コピー)**:
    - `@PE1 = { |L, 0, 3, 6, 8, ... }` 形式でリアルタイム生成、ワンクリッククリップボードコピー。
    - 同一生成ロジック（`generateMmlSnippet`）が `▶ MMLに反映` ボタンと共有されており、エディタヘッダーから直接MMLへの挿入も可能。
  - **Web Audio リアルタイム試聴**:
    - A4 (440Hz) ソートゥース波オシレーターを用い、1フレーム（約16.6ms）ごとに `pitch * 25 cents` のデチューン変調を適用。ビブラートやピッチベンドの聴感効果を忠実にシミュレート。

### 3.7 楽曲セットアップパネル (`SongSetupPanel.tsx`)
右ペインの第5タブ（`SONG SETUP`）に配置。エディタで開いている楽曲MML固有のメタデータ（タイトル、作曲者）やコンパイル・音源ディレクティブ（#OPM, #OCTAVE）を設定・管理するパネル。
**MMLエディタと双方向でリアルタイム完全同期（Single Source of Truth）**する設計。

- **Bento Card 構成**:
  - **Bento Card 1 (SONG METADATA - 楽曲メタ情報)**:
    - `#TITLE`: 楽曲タイトルを入力・編集（MMLヘッダーの `#TITLE "..."` と即座に同期）。
    - `#COMPOSER`: 作曲者・アレンジャー名を入力・編集（MMLヘッダーの `#COMPOSER "..."` と即座に同期）。
  - **Bento Card 2 (SOUND CHIPS FOR THIS SONG - 楽曲別音源構成)**:
    - **ACZ-8BS1MZ (YM2151 FM Sound Board) トグルスイッチ**:
      - この楽曲で拡張FM音源（4オペレータFM 8ch: `F1`〜`F8`）を使用するかを指定（ON/OFF）。
      - スイッチONでMMLヘッダーに `#OPM ON` を追記/置換。OFFで `#OPM OFF` に置換。
      - トグル状態は右ペインの「YM2151 TONE」タブの有効/無効バッジやトラックモニターの17ch/9ch表示とも完全連動。
    - **実機標準音源 (DCSG & BEEP) インフォメーション**:
      - 実機標準音源（P1〜P6 矩形波6ch + N1〜N2 ノイズ2ch + B1 BEEP 1ch = 計9ch）は常時アクティブであることを明示。
  - **Bento Card 3 (MML DIALECT CONVENTIONS - MML記法・方言ディレクティブ)**:
    - **#OCTAVE オクターブ記法規則切替**:
      - `NORMAL (デフォルト)`: `<` で1オクターブ下げる、`>` で1オクターブ上げる。
      - `REVERSE (逆向き)`: `<` で1オクターブ上げる、`>` で1オクターブ下げる。
      - 選択されたボタンに応じて、MMLヘッダーの `#OCTAVE NORMAL` または `#OCTAVE REVERSE` と双方向同期。
  - **Bento Card 4 (SYNCHRONIZED MML DIRECTIVES - リアルタイム同期プレビュー)**:
    - パネル上で設定された全ディレクティブ（`#TITLE`, `#COMPOSER`, `#OCTAVE`, `#OPM`）をリアルタイムにカード内にコードブロック表示し、アクティブMMLとの同期状態を視覚的にフィードバック。
