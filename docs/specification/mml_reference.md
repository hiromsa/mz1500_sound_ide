# MZ-1500 MML リファレンス仕様書 (`docs/specification/mml_reference.md`)

本書は、MZ-1500 Sound IDE における MML（Music Macro Language）コンパイラおよびサウンドドライバ向けの言語仕様・コマンドリファレンスです。
各コマンドの英語名（由来・覚え方）、音源チップ別の対応状況、ディレクティブ定義、およびエンベロープ/音色マクロの書式を網羅しています。

---

## 1. ヘッダーディレクティブ & 方言設定

MMLファイルの冒頭（トラック記述の前）に `#` から始まるディレクティブを記述し、曲のメタデータやMML記法の方言を設定します。

| ディレクティブ | 英語名 / 由来 | 書式例 | 説明 |
| :--- | :--- | :--- | :--- |
| `#TITLE` | **Title** | `#TITLE "Theme of MZ"` | 楽曲のタイトルを指定します。コンソールやエクスポート時に表示されます。 |
| `#COMPOSER` | **Composer** | `#COMPOSER "User"` | 作曲者・編曲者名を指定します。 |
| `#OCTAVE` | **Octave Direction** | `#OCTAVE NORMAL`<br>`#OCTAVE REVERSE` | `<` と `>` のオクターブ増減方向を切り替えます。<br>・`NORMAL`（デフォルト）: `<` で下げる、`>` で上げる。<br>・`REVERSE`: `<` で上げる、`>` で下げる。 |
| `#OPM` / `#FM` | **OPM / FM Sound Board Option** | `#OPM ON`<br>`#OPM OFF` | 拡張FM音源ボード（ACZ-8BS1MZ / YM2151）の有効/無効を指定します（標準デフォルト: OFF）。<br>・SETTINGSパネルのスイッチとリアルタイムに相互連動します。<br>・`#FM ON` / `#FM OFF` も同等のエイリアスとして認識されます。 |

## 2. トラック構成 & 音源チップ対応マトリクス

MZ-1500 Sound IDE は全17トラックに対応しています。

| 系統 | トラック表記 | 対象音源チップ | チャンネル数 | 特徴 |
| :--- | :--- | :--- | :---: | :--- |
| **DCSG 1** | `P1`, `P2`, `P3`, `N1` | SN76489 (標準) | 4ch | 矩形波3ch + ノイズ1ch |
| **DCSG 2** | `P4`, `P5`, `P6`, `N2` | SN76489 (標準) | 4ch | 矩形波3ch + ノイズ1ch |
| **BEEP** | `B1` | 8253 PIT (標準) | 1ch | 1bit パルス矩形波 |
| **FM音源** | `F1`〜`F8` | YM2151 / OPM (拡張ボード ACZ-8BS1MZ) | 8ch | 4オペレータ FM音源 8ch |
| **作業用 (Work)** | `W1`〜`W99` | 実機演奏外（素材退避・プール） | 任意 | PSG互換文法。MIDI Import 時の溢れトラック保持用。実機バイナリ出力・演奏時は自動スキップ。MML TRANSFORM で後から実機へ配分可能。 |

| **ディチューン (`D`)** | **○** | **○** | **×** | **○** | 基本ピッチの微調整オフセット |
| **FM音色マクロ (`@`, `@FM`)** | **○** | **×** | **×** | **×** | YM2151専用（OP1〜OP4レジスタ一括転送） |

| **ノイズ波形 (`@WN`)** | **×** | **×** | **○** (`@WN0`/`@WN1`) | **×** | 周期ノイズ / ホワイトノイズ切替。音高は c/e/g の 3 段階シフトレート |
| **ノイズ統合 (`@IN`)** | **○** (`P3`, `P6` のみ) | **×** | **×** | **×** | トーン 3 の周波数レジスタでノイズジェネレータを駆動 (発音もノイズへ切替) |

## 3. ジャンル別 コマンド一覧

### 3.1 基本・音符・休符 (Notes & Timing Basics)

| コマンド | 英語名 / 由来 | 書式例 | 説明 | 対象 |
| :--- | :--- | :--- | :--- | :--- |
| `c d e f g a b` | **Scale Notes** | `c`, `d+4`, `f-8.` | 音符（ドレミファソラシ）。`+` または `#` で半音上げ、`-` で半音下げ。直後に数値を記述して音符長を指定（省略時は `l` の値）。付点 `.` にも対応。 | 全音源 |
| `r` | **Rest** | `r4`, `r16` | 休符。長さをあとに続けて指定可能。 | 全音源 |
| `^` | **Tie** | `c4^8` | タイ。直前の音符の発音を後ろの音符分だけ延長して繋げます。 | 全音源 |
| `{ } n` | **Tuplet** | `{gag}2`, `{cde}4` | 連符。中括弧内の複数の音符を指定した長さ（`n`）の中で均等に発音します。 | 全音源 |
| `q` | **Quantize** | `q7` | クオンタイズ（ゲートタイム比率）。`1`〜`8`。標準は `7`。ゲートは 1/60 秒フレーム単位で量子化され、**ノート開始フレームを含む `gate` フレーム分発音**します。`q8` = ゲート＝音長で、音符境界に無音フレームを挟まないスラー演奏になります。 | 全音源 |
| `@q` | **Quick Cut (Frame Quantize)** | `@q1`, `@q3` | フレーム単位のゲートカット。音符の末尾を指定フレーム数（1/60秒単位）だけ強制消音して歯切れよくします。 | 全音源 |

### 3.2 オクターブ & 移調 (Octave & Transpose)

| コマンド | 英語名 / 由来 | 書式例 | 説明 | 対象 |
| :--- | :--- | :--- | :--- | :--- |
| `o` | **Octave** | `o4` | オクターブ絶対指定（`o1`〜`o8`）。標準は `o4`（中央ド周辺）。 | 全音源 |
| `<` `>` | **Octave Step (Down / Up)** | `<`, `>` | オクターブの相対変更。標準では `<` で1オクターブ下げ、`>` で1上げ（`#OCTAVE REVERSE` 指定時は逆）。 | 全音源 |
| `K` | **Key Transpose** | `K-2`, `K3` | トランスポーズ（移調）。半音単位で後続のすべての音符ピッチを一括で平行移動（正負可能）。`K0` でリセット。大文字必須。 | 全音源 |

### 3.3 テンポ & 演奏速度 (Tempo & Speed)

| コマンド | 英語名 / 由来 | 書式例 | 説明 | 対象 |
| :--- | :--- | :--- | :--- | :--- |
| `t` | **Tempo (BPM)** | `t120`, `t150` | 曲のテンポ指定（BPM：1分間あたりの四分音符数）。 | 全音源 |
| `@t` | **Tempo Frame** | `@t1,86` | フレーム単位（1/60秒）による高精度テンポ指定。書式: `@t<音符長>,<何フレームか>`。 | 全音源 |
| `l` | **Length (Default Length)** | `l8`, `l16` | デフォルトの音符長を指定（`l4`=4分音符、`l8`=8分音符）。数値省略時の長さとなります。 | 全音源 |

### 3.4 音量 & ボリュームエンベロープ (Volume & Envelope)

| コマンド | 英語名 / 由来 | 書式例 | 説明 | 対象 |
| :--- | :--- | :--- | :--- | :--- |
| `v` | **Volume** | `v15`, `v8` | 音量指定（`0`=無音 〜 `15`=最大音量）。**※BEEP不可** | FM / PSG / Noise |
| `@v` | **Fine Volume (FM)** | `@v100`, `@v0` | FM専用の高分解能音量指定（`0`=無音 〜 `127`=最大音量）。YM2151 の TL (Total Level) レジスタへ `TL = 127 - @v` として全オペレータに一括反映します（約0.75dB/ステップ）。FMトラック以外では警告が出て無視されます。即値指定のため `@VE`（音量エンベロープ）適用中に指定した場合はエンベロープを解除します。`v` / `@v` / `@VE` は後から指定したものが有効になります。 | FM専用 (`F1`〜`F8`) |
| `@VE` | **Volume Envelope** | `@VE1` | 音量エンベロープ（後述）の適用。引数なし（`@VE`）または `@VE0` でエンベロープ解除。 | PSG / Noise |

### 3.5 ピッチ & 効果音 (Pitch, Sweep & Envelope)

| コマンド | 英語名 / 由来 | 書式例 | 説明 | 対象 |
| :--- | :--- | :--- | :--- | :--- |
| `D` | **Detune** | `D10`, `D-8` | ディチューン指定。レジスタ差分値でトラック全体のピッチを微調整（正=上昇、負=下降）。`D0` で解除。 | FM / PSG / BEEP |
| `@SW` | **Pitch Sweep** | `@SW-20`, `@SW15` | ピッチスイープ（周波数ベンド）。毎フレームごとに指定値ずつピッチを変化させます。`@SW0` で解除。 | FM / PSG / BEEP |
| `@PE` | **Pitch Envelope** | `@PE1` | ピッチエンベロープ（ビブラート・音程変化）の適用。引数なし（`@PE`）または `@PE0` で解除。 | FM / PSG / BEEP |

### 3.6 音色・ノイズ・FM制御 (Voice & Noise Control)

| コマンド | 英語名 / 由来 | 書式例 | 説明 | 対象 |
| :--- | :--- | :--- | :--- | :--- |
| `@` / `@FM` | **Voice / FM Voice** | `@1`, `@FM1` | FM音色マクロ（後述）の適用。FM音源トラック（`F1`〜`F8`）にて有効。 | FM専用 |
| `p` | **Panpot (Stereo)** | `p0`, `p3` | ステレオ定位を指定します。`p0`: 無出力 / `p1`: 左出力 / `p2`: 右出力 / `p3`: 左右出力（中央・初期値）。 | FM専用 |
| `@WN` | **Waveform Noise** | `@WN1` | ノイズ波形指定。`@WN0`: 周期ノイズ（金属音・PSG風）, `@WN1`: ホワイトノイズ（爆発・スネア・標準・**初期値**）。音高は音符で `c`（低）/ `e`（中）/ `g`（高）の **3 段階シフトレート**のみ（実機仕様）。 | Noise専用 (`N1`,`N2`) |
| `@IN` | **Integrate with Noise** | `@IN1` | トーン 3 トラック（`P3`, `P6`）のノイズ統合モード。自身の周波数レジスタでノイズジェネレータを駆動し、**発音もノイズチャンネルへ切り替わる**（トーン 3 自体は無音化・音量 `v` はノイズ減衰へ適用）。音高は `cdefgab` の通常の音符で自由に指定。<br>・`@IN0`: 統合解除（**初期値**。通常の矩形波に戻り、ノイズチャンネルを解放）<br>・`@IN1`: 周期ノイズ連動（デューティ比の偏った硬いパルス波）<br>・`@IN2`: ホワイトノイズ連動（音階に追従するノイズ） | `P3`, `P6` 専用 |

> **ノイズチャンネルの詳細**: `@WN` / `@IN` の組み合わせ挙動、P3 / P6 との同期原理 (tone2 共有)、LFSR の仕組み、ドライバ実装、MML 記述例、FAQ は [noise_channel.md](./noise_channel.md) に総合仕様としてまとめています。

### 3.7 フロー制御・ループ (Flow Control & Comments)

| コマンド | 英語名 / 由来 | 書式例 | 説明 | 対象 |
| :--- | :--- | :--- | :--- | :--- |
| `[ ] n` | **Loop / Repeat** | `[cde]2`, `[[c]2e]2` | 繰り返しループ。括弧内のフレーズを `n` 回繰り返します（`n` 省略時は2回）。多重入れ子に対応。 | 全音源 |
| `L` | **Loop Point** | `L` | 楽曲全体の永久ループポイント。曲の終端に達した際、このマーカー位置へ戻って演奏をループします。 | 全音源 |
| `;` `/` | **Comment / Slash** | `; メモ`, `/ コメント` | コメント。記述以降、その行の末尾までが演奏時に無視されます。 | 全音源 |

## 4. エンベロープ & 音色マクロの定義書式

### 4.1 音量エンベロープ (`@VE`)
曲の先頭などで `@VE[番号] = { 音量推移 }` の形式でマクロを定義し、トラック内で呼び出すことで適用します。

* **値域**: `0` (無音) ～ `15` (最大音量)
* **推移速度**: 毎フレーム (1/60秒) ごとに1要素進む
* **連続指定**: `値 x 回数`（例: `15x3`）で同じ値を省略記法できる
* **ループ**: `|` 記号を挟むと、末尾到達時にそこへ戻ってループする。`>` 指定時はノートON中のループ区間が `|` ～ `>` の直前までに限定され、演奏中にリリース区間へ突入することはない（`>` のみ指定で `|` なしの場合は `>` の直前でホールド = サステイン）
* **リリース(余韻)**: `>` 記号以降の要素は、ノートOFF（ゲート終端 / 休符）後に再生される余韻部分となる。リリースはキーオフのタイミングで 1 回だけ再生され、休符だけで再始動することはない（`@VE`のみ対応、`@PE`では使用不可）

> **`@v` について**: `@v` はかつて `@VE` のエイリアスでしたが、音量エンベロープは `@VE` に一本化し、`@v` は **FM 専用の音量コマンド (`@v0`〜`@v127`) として再実装** しました（2026-09-07 確定・3.4 参照）。旧エイリアスの定義行 `@vN = { ... }` はマクロ定義として認識されずコンパイルエラーになるため、音量エンベロープは `@VEN` / `@VE` に書き換えてください。

```mml
; 定義例
@VE0 = {15, 12, 9, 6, 3, 0}                    ; 減衰音（ピアノやギター風）
@VE1 = {15, 14, 13, |, 11, 10}                 ; 10まで下がったら11へ戻ってループ
@VE2 = {15x4, 10x4, 5x4, 0}                    ; 15,15,15,15, 10,10,10,10... と展開される
@VE3 = {15, 14, 13, |, 12, 11, >, 8, 5, 2, 0}  ; ループ+リリース付き（ノートOFF後に8,5,2,0と減衰）
```

### 4.2 ピッチエンベロープ (`@PE`)
音の高さを連続的に変化させます（ビブラートやピッチスイープ）。
定義の記法は音量エンベロープ (`@VE`) と同じです。`|` によるループに対応します（リリース `>` は `@VE` のみ対応）。

* **値域**: **PSGレジスタ差分値**。正の値＝音程上昇、負の値＝音程下降。値が大きいほど変化が大きい。

```mml
; 定義例
@PE0 = {0, 5, 10, 15, 20}         ; 徐々にピッチが上がるスラー
@PE1 = {5, -5, |, 5, -5}          ; 素早いビブラート
@PE2 = {0x5, 10x5, 20x5, 30x5}    ; ポルタメント階段

; エイリアス表記 @EP も使用可能
@EP3 = { |, 0, 3, 6, 8, 6, 3, 0 }
```

### 4.3 FM音色マクロ (`@` / `@FM`)
YM2151 (OPM) 向けの4オペレータFM音色パラメータ（全 46 パラメータ）を定義します。
`@<番号> = { ... }` または `@FM<番号> = { ... }` の形式（`=` 必須）で、
先頭に ALG / FB の 2 値、続けて OP1〜OP4 各 11 パラメータをカンマ区切りで記述します。

| 区分 | パラメータ順 |
| :-- | :-- |
| 共通 (2 値) | `ALG`, `FB` |
| OP1〜OP4 (各 11 値) | `AR`, `D1R`, `D2R`, `RR`, `D1L`, `TL`, `KS`, `MUL`, `DT1`, `DT2`, `AME` |

> **`AME` について**: `AME` は振幅変調（トレモロ）の有効フラグで、一般的な 4 オペレータ FM 音色データの OP 構成に合わせて定義に含めています。ただし **本ドライバでは未実装** で、値を設定しても音には影響しません。MZSD バイナリ上も 46 パラメータのうち最終 1 パラメータは未使用（予約）領域として格納されます。

```mml
; FM音色定義 @1（または @FM1）
@1 = {
  /* ALG=4, FB=6 */
  4, 6,
  /* OP1: AR, D1R, D2R, RR, D1L, TL, KS, MUL, DT1, DT2, AME */
  31, 12,  0, 15,  3, 24, 0, 1, 0, 0, 0,
  /* OP2 */
  31, 18,  0, 12,  5, 18, 0, 2, 3, 0, 0,
  /* OP3 */
  31, 10,  0, 15,  2, 30, 0, 1, 0, 0, 0,
  /* OP4 (Carrier) */
  31,  8,  0,  8,  4,  0, 0, 1, 0, 0, 0
}

; @FM 表記でも同様に定義可能
@FM2 = { ... }
```

## 5. MML 実例サンプル

```mml
#TITLE "MZ-1500 Theme"
#COMPOSER "User"
#OCTAVE NORMAL

; 音量・ピッチエンベロープ定義
@VE1 = { 15, 14, 13, 12, |, 11, >, 8, 4, 0 }
@PE1 = { |, 0, 2, 4, 2, 0, -2, -4, -2 }

; FM音色定義
@FM1 = {
  4, 6,
  31, 12, 0, 15, 3, 24, 0, 1, 0, 0, 0,
  31, 18, 0, 12, 5, 18, 0, 2, 3, 0, 0,
  31, 10, 0, 15, 2, 30, 0, 1, 0, 0, 0,
  31,  8, 0,  8, 4,  0, 0, 1, 0, 0, 0
}

; --- DCSG トラック演奏 ---
P1 t120 l8 o4 @VE1
P1 c e g > c < g e c r
P1 L [c d e f g2]2

; --- FM トラック演奏 ---
F1 t120 l8 o4 @FM1 @v110
F1 c4 e4 g4 > c2 <
F1 L [c4 d4 e4 f4]2
```
